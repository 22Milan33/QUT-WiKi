# 防骗防诈
>欢迎来到大学，从高中的象牙塔出来，马上就是小型社会化的大学生活，在大学里，难免会遇到一些不良分子，甚至是骗子。为了让大家在大学生活中能够更好地保护自己，避免上当受骗，特整理了以下防骗防诈的相关知识。

## 1. 开学报到诈骗（一定要注意，多人被骗）

开学报到流程为，纸上报道刷脸————扫报道单————班助报道————领军训服，在纸上报道阶段，会有人坐在那跟个人一样让你交钱扫码，差不多二百块钱，一定不要交钱，这是中国移动的电话卡，相当于没问你的意见直接给你办了，这个时候不用管他直接去下一步报道就行，如果已经被骗了交钱了，路边激活的先别管，你直接找那个让你交钱的人，可以当场退，如果是激活了的，去找营业厅，校内的可以销户，把钱转到其他你移动的号上。

## 2. 诈骗的常见类型

### 校园网与校园卡

我们首先要知道校园网和校园卡完全不是一种东西，简单来讲，校园网就是覆盖校园的WiFi网络(建筑内效果好&无流量限制)，而校园卡就是一张大流量的电话卡(建筑外效果好&有流量限制)。

- 学校内任何官方网站/系统**都不需要校园网进入**，外网也可以直接访问
- 如果有所谓的学长学姐向你推销校园卡，一定要想清楚你自己**是否真的需要大流量卡**
- 看清所谓校园卡的套餐内容，这种校园卡流量一般包括小部分的全国通用流量和**大部分高校流量(只能在校园里使用)**
- 校园卡内一般会包含一些杂七杂八的，没有必要的额外费用，比如**云盘，彩铃**等等，可以自己致电运营商客服取消这些不必要的服务
- 还有一个重要事实，**校园网的缴费和校园卡的缴费没有任何关系**，不要相信所谓的“开通校园卡享受低价10元的校园网”

### 生活用品配送到宿舍

- 这里的生活用品指被褥，洗漱用品等等，现在网购和快递如此发达，就算你觉得开学从家里带来被褥相当之麻烦，你也完全可以**网购到学校**。
- 网购有**淘宝，京东，拼多多**等等如此庞大的平台背书，种类繁多，价格透明，售后有保障。
- 相比之下，“学长学姐”与你交易，在微信QQ这种社交软件上，无法确认身份，**交易完全不可信**，甚至你付钱之后拉黑你。
- 即使他是**企业微信**用户，也不要轻信，毕竟每年这种贩子能大肆赚钱的时候就是新生入学

### 兼职刷单

- 刷单是一种违法行为，不仅违反了平台规则，还可能涉及诈骗等犯罪行为。
- 任何要求先交押金、保证金或手续费的“兼职”都是骗局，切勿相信。
- 如果遇到此类情况，应立即停止联系并报警。

### “新生交流群”

- 所谓的“新生交流群”也许真的是本校学长学姐所建立，不过他们的最终目的也是推销产品。他们的一次推销的佣金能达到百元之数，一个暑假业绩好的话，能到达千数之多。
- 其实从日后社交来看，新生交流群并不是那么必要的，日后机会多得多。

### 关注某某公众号赠与小礼品

- 关注公众号赠送小礼品的活动，往往是为了收集个人信息，甚至可能涉及诈骗。
- 记住不要贪图小便宜。
