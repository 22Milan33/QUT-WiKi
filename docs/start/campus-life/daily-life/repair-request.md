# 故障报修

## 权益反馈渠道

如果大家碰到：**饮水机、洗衣机、水龙头**等公共设施故障，**宿舍墙体发霉、门窗损坏**，或是对校园环境、生活服务有改进想法，可以直接把情况反馈给**本班生活委员**。

生活委员会统一收集，上报到学院生活权益部，由院生活权益部对接学校相关部门，尽力推进问题解决。
欢迎大家理性合理反馈，一起把校园生活环境变得更好！

## 具体报修途径

各位同学，公寓暖气，用电，浴室，门窗和教室等保障维修问题，有同学不太清楚报修途径，途径有:

1. 黄岛校区报修电话 **68052288** 。
2. 关注微信公众号“**青岛理工大学后勤**”进行线上报修。
3. 对于空调设备故障问题可以反映给各公寓一楼值班人员报修，由学生处具体负责联系维修。
4. 宿舍楼或者教学楼饮水机问题可以直接打 **15165260589** 进行报修，比较快一点。
